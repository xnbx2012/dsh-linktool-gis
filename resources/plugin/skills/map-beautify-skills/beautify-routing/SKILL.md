# plan0701 Workflow 边界

- 本 Skill 仅用于完整 Workflow 的 Deliver 阶段或已有地图成果的后处理美化。
- 不得作为完整复杂任务的独立 Workflow，也不得替代 GIS 分析、制图字段统计或成果验收。

# 目标

接收用户的"美化地图"请求 + 一张底图 PNG/JPG，按知识库的分类规则与美化原则，**自行拼装正面 + 负面提示词**，然后调 `beautify_image(image_path, prompt, negative_prompt)` 完成图生图美化。

**字数铁律**：
- 正面提示词 ≤ 300 个中文字符
- 负面提示词 ≤ 200 个英文字符
- 正负面总计 ≤ 500 字符（模型注意力上限）

本 SKILL 是 Claude Code 的执行说明书。`Map_Beautify/main.py` 不参与拼词、不读 skills、不做别名映射；所有语义工作由你（搭载在 Claude Code 上的 LLM）完成。

## 1. 识别底图主题大类

必读 `themes.md`。

- 从 8 大类中选最匹配的 **1 个**：基础底图 / 连续数值场 / 密度热力 / 分级统计 / 流向 / 叠加分析 / 三维与影像 / 历史古典
- 若命中某子类（如 `行政区划图`、`经济 / GDP`、`地形`），同时记下子类名
- 底图肉眼无法识别时，按用户提示词字面归类
- 仍无法归类 → 按用户原话直通（不强行映射）

输出：`{大类名, 子类名 or None}`

---

## 2. 选定地图风格

必读 `styles.md`。

- 从 6 大类中选 **1 个**：写实 / 3D 地形 / 扁平化 / 复古 / 手绘 / 信息图地图
- 命中子类则用子类（如 `带云雾大气透视`、`民国风`、`水彩`、`卡通 Q 版`）
- 用户给的风格词若 6 大类与子类都不命中（如"赛博朋克"、"蒸汽波"）：**按用户原文为最高标准**，不强行映射；本步骤的输出短语直接用用户原词（如"赛博朋克视觉"）

输出：`{风格短语 ≤30 字}`

---

## 3. 选定功能用途

必读 `purposes.md`。

- 从 3 大类中选 **1 个**：科研图 / 直观图 / 宣传图
- 用户语义近似词归并：学术图/论文图→科研图；大众图/新闻图/科普图→直观图；海报/展览图/广告图→宣传图

输出：`{用途短语 ≤30 字}`

---

## 4. 套用美化原则

必读 `principles.md`。

应用 6 条规则：

1. 不增减原始地理数据/要素/图幅
2. 满足基本制图规范（指北针/比例尺/图例/图框）
3. 用户提示词为最高标准
4. 未命中 skills 分类时原文直通
5. skills 给的配色是例子不是答案
6. 冲突时遵循 **功能用途 > 地图主题 > 地图风格**

冲突示例：风格说"做旧米黄"但用途是"科研图"——选科研图（功能用途优先），即米黄做旧降至辅助元素，主体保留科学色板。

---

## 5. 拼装 prompt（视觉短语流，≤300 中文字符）

按"倒金字塔三梯队"模板。逗号合并、句号分段；正面提示词中**严禁出现否定词**（如"不得""不要""严禁"），所有禁止事项翻译成英文反向特征词，放入负面提示词。

### T1 用户个性化（最前）

- 若用户给了 `主题标题`：写成 `《标题》{字体描述}置图幅顶部`
  - 字体描述由 **风格主导**：赛博朋克→霓虹荧光大字；复古/民国→做旧衬线/竖排宋体大字；扁平化→现代无衬线大字；水墨→毛笔书法大字；3D 地形→立体浮雕大字
  - 风格未给明确信号时，按功能用途默认：科研→宋体衬线规范字；直观→黑体规范大字；宣传→醒目装饰大字
- 若用户给了 `地图内容`（个性化要求，如"霓虹光边国界线"、"古典纹样四角装饰"）：句号分隔，逐条转视觉短语

### T2 主体定性 + 用途 + 风格

```
一张{底图描述}二维平面地图，{用途短语}，{主题短语}，{风格短语}风格
```

- `底图描述` 取自用户的 `图片内容描述` 参数（如"欧洲各国家行政区划"、"广东县域 GDP 热力分布"）
- `主题短语` 取自第 1 步（命中子类则用子类详细短语；命中大类则用大类骨架短语）
- `用途短语` 取自第 3 步
- `风格短语` 取自第 2 步
- **配色美化**：根据风格与主题调整点、线、面要素的配色及对应图例颜色，使之更美观、和谐（见 `principles.md` 规则 6）

### T3 制图要素 + 正向几何锚点（固定模板）

```
包含清晰图例指北针比例尺，二维顶视图，地理轮廓与边界水系几何精准
```

### 拼接

`T1。T2。T3。` —— 三段用句号分隔。

### 字符上限

正面提示词总长度 ≤ 300 中文字符。超出时**保头不保尾**：T1 最优先保留，T3 最后截断。

---

## 5.5 拼装负面提示词（英文，≤200 字符）

必读 `negative_prompts.md`。

根据当前**地图主题 + 地图风格**，从词库中选择最相关的 5-10 个英文特征词，用逗号+空格连接。

**选取逻辑（通用原则）**：
1. 基线必选：从地理变形类选 1-2 个，从裁剪旋转类选 1-2 个
2. 若正面提示词含文字标注/标题 → 追加文字乱码类 1-2 个
3. 若主题为连续数值场/分级统计 → 追加抽象污染类 1-2 个
4. 所有地图追加三维场景类 1-2 个（防止地图被画进三维场景）
5. 收尾：水印标识类 1 个

**反面教材**：不要把 negative_prompts.md 中全部 40+ 个词都堆上去，会导致注意力稀释。控制总长度 ≤200 字符。

**示例**（仅示范格式）：
```
distorted boundaries, fake geography, 3d scene, cropped map, garbled text, watermark
```
（约 90 字符，达标）

## 6. 调用 beautify_image

```python
beautify_image(
    image_path="<用户传来的底图绝对路径>",
    prompt="<Step 5 拼好的 ≤300 字符正面 prompt>",
    negative_prompt="<Step 5.5 拼好的 ≤200 字符英文负面 prompt，必填>",
    # 可选
    variant="<多轮对比时填变体名，如 'A1'>",
    output_dir="<不传则用 Map_Beautify/result/>",
)
```

工具返回输出图片绝对路径或以"错误："开头的诊断字符串。

## 豆包工具特殊条件（默认锁定）

仅当用户**本轮对话消息**中明确出现下列触发词之一：

- `豆包` / `seedream` / `seedra` / `dream`
- 典型短语："用豆包测"/"切换豆包"/"换豆包"/"用 seedream 跑一次"/"豆包上场"

才可调 `beautify_image_doubao`。其余任何情况一律调 `beautify_image`（Qwen-Image-Edit）。

调用 `beautify_image_doubao` 时：

- 必填 `user_explicit_request`：填用户本轮的**触发原话片段**（≥4 字且含触发词），如 `"用豆包测 test_E"`
- 工具内部会做第二层校验，触发词缺失时直接拒绝执行，不消耗 API
- 在对话回复里明确告知用户："将调用豆包（珍贵模型），消耗 API 配额"

豆包用完一轮，**默认回到锁定状态**，下一轮请求不带触发词时回 Qwen。

## 不命中分类时的处理（"原文直通"原则）

- 主题：用户字面无法归入 8 大类 → T2 的 `主题短语` 直接用用户原话（如"古地图叙事图"）
- 风格：6 大类不命中 → T2 的 `风格短语` 直接用用户原话 + "视觉"二字（如"赛博朋克视觉"）
- 用途：3 大类有同义词归并空间，几乎不会不命中；真不命中则用 `用作{用户原词}`

不强行映射 = 让 Qwen 直接对齐用户字面诉求；强行归类反而会把"赛博朋克"压成"扁平化"导致失真。
