# conclusion-report

## 1. 适用场景

用于生成结论型、评价型、建议型报告，重点回答“结果说明什么、问题在哪里、原因可能是什么、下一步该怎么做”。

适用：
- 耕地质量评价报告
- 三普/三调成果解读
- 适宜性、等级、风险、问题诊断
- 面向领导或技术人员的结论报告

不适用：
- 工具执行过程复盘 → 使用 `/tool-report`
- Office 文件生成 → 使用 `/officecli`

## 2. 输入与分析来源

分析来源：
- `task_plan.md`：原始目标、验收标准、关注问题。
- `gis-tool-logs.json`：技术路线与结果来源。
- 最终结果数据：位于 `03_Result/`。
- 统计分析：优先调用 `/data-analyzer`；必要时用 MCP 获取字段、样本和元数据。
- 领域依据：用户提供的标准、阈值、规范；不得臆造标准值。

## 3. 工作流

1. 解析用户需求：报告类型、受众、篇幅、标准、重点问题。
2. 确定分析对象：数据集、字段、评价单元、空间范围。
3. 获取统计结果：调用 `/data-analyzer` 或 MCP 查询。
4. 构建报告结构：按受众和标准动态选择章节。
5. 深度解读：现状 → 含义 → 关联 → 原因 → 建议。
6. 分段写入 Markdown。
7. 自检：每个结论都有数据来源，每条建议能对应问题。

## 4. 动态报告结构

按用户目的选择结构：

- 简报/面向领导：概述 → 核心发现 3-5 条 → 主要建议 → 风险提示。
- 技术报告/面向专业人员：背景与数据 → 方法 → 统计结果 → 空间差异 → 问题诊断 → 建议 → 结论。
- 标准化评价报告：优先遵循用户指定标准章节；未指定标准时，不冒充国家规范。
- 单指标重点分析：该指标单独成章，其他指标作为解释变量或背景。
- 多因子综合评价：说明权重、分级、叠加逻辑，再解释等级分布和限制因素。

## 5. 深度分析规则

每个重要结论按 5 层展开：

1. 描述现状：给出真实统计值、空间分布或等级比例。
2. 解释含义：说明该值代表的质量、风险、适宜性或限制。
3. 关联分析：结合地形、土壤、土地利用、区位、管控线等因素解释差异。
4. 原因推断：只做有依据的推断；不确定时写“可能与……有关，需要进一步验证”。
5. 对策建议：建议必须可执行，并对应已识别问题。

禁止：
- 只复述 `/data-analyzer` 的文字。
- 没有统计依据就下结论。
- 引用用户未提供且未检索验证的标准阈值。
- 对所有区域给同一种笼统建议。

## 6. 写作模式

推荐段落结构：

- 现状句：`研究区 [对象] 共 [数量/面积]，其中 [类别] 占比 [比例]，主要分布在 [空间位置]。`
- 解释句：`这表明 [现象]，对 [农业生产/建设适宜性/生态风险] 的影响是 [影响]。`
- 关联句：`结合 [相关因素] 看，[高/低值区] 与 [因素] 空间上基本一致，说明 [解释]。`
- 谨慎推断句：`该现象可能与 [原因] 有关，但仍需结合 [补充数据] 进一步验证。`
- 建议句：`建议对 [区域/对象] 采取 [措施]，优先解决 [问题]。`

## 7. Few-shot 示例

### 示例 1：面向领导的简报

输入统计：适宜区 62%，一般适宜区 28%，不适宜区 10%。

写法：
本次分析显示，研究区总体建设适宜性较好，适宜区占 62%，主要集中在地势较平坦、交通可达性较高的片区。一般适宜区占 28%，多位于适宜区外围，可作为后续弹性拓展空间。不适宜区占 10%，主要受坡度或生态约束影响，建议原则上避让。

### 示例 2：单指标土壤 pH 分析

输入统计：pH 平均值 5.6，低值区集中在丘陵坡地。

写法：
土壤 pH 平均值为 5.6，整体偏酸。空间上，低 pH 区主要集中在丘陵坡地，与坡度较大、淋溶作用较强的区域相吻合。该特征可能限制部分作物养分吸收，建议在低 pH 连片区域优先开展酸化改良，并结合地块经营情况确定石灰或有机肥施用方案。

### 示例 3：耕地质量综合评价

输入统计：高等级耕地 35%，中等级 50%，低等级 15%。

写法：
评价结果表明，研究区耕地质量以中等级为主，占 50%，说明整体生产基础稳定但优质耕地比例仍有提升空间。高等级耕地占 35%，主要分布在地形平缓、土壤条件较好的区域，是粮食稳产的核心空间。低等级耕地占 15%，其限制因素可能与坡度、土壤肥力或灌排条件有关，建议将其作为后续改良工程和高标准农田建设的重点识别对象。

### 示例 4：限制因素诊断

输入统计：限制区与高坡度区重叠率 78%。

写法：
限制区与高坡度区的空间重叠率达到 78%，说明坡度是影响本次适宜性评价的主要约束因素。此类区域开发成本高，且可能增加水土流失风险。因此，建议在规划中将高坡度限制区作为刚性避让或低强度利用区域，同时优先在坡度较低且交通条件较好的片区安排新增建设或整治项目。

## 8. 自检清单

交付前检查：

- 报告结构匹配用户受众和用途。
- 每个关键结论至少有一个数据来源。
- 统计值、面积、比例、等级不矛盾。
- 原因推断使用谨慎表达，并说明依据。
- 建议与问题一一对应，且可执行。
- 未冒用未验证的标准、阈值或政策条文。
## plan0701 Workflow 边界

- 结论报告必须消费同一完整 Workflow 的分析产物、统计结果、图件和日志。
- 不得在 Workflow 外独立补做主体 GIS 分析或编造统计。
