# 视觉核验 · 操作类型分类法参考

本文件是 `visual-check` Skill 的配套参考库。读图前**先按本次 `operation_type` 查到对应工具条目**，
取其「必叠参考层 / 正面信号 / 负面信号 / 视觉↔数据交叉项」组装本次检查清单；未列出的工具
用下方 **A. 通用症状库** 兜底。

**铁律**：只判**数据问题**，绝不评价美观/配色/排版/标注。
**数据交叉用到的 MCP 工具**（均为 `gis-tool` Agent 可调）：
- `query_feature_attributes(feature_path, sql_where, max_records)` → 返回 `total`/`returned`/`data`，用 `sql_where` 数异常值
- `get_data_properties(data_path)` → 返回 `coordinate_system.{name,wkid,unit}`、`extent.{xmin,ymin,xmax,ymax}`、`feature_count`、`shape_type`
- `list_gdb_contents(gdb_path)` → 列要素类，确认目标是否生成

> 字段名约定：GDB 要素类的面积/长度字段为 `Shape_Area` / `Shape_Length`；SHP 默认无面积字段，
> 需用已计算的面积字段或先算几何。下文 `Shape_Area` 按 GDB 习惯书写，按实际字段替换。

## A. 通用症状库（跨工具主表）

读图看到任一症状 → 按本表归类、执行交叉确认、并据"常见成因/修复方向"填写溯源链。

| 症状 | 视觉特征 | 归类 | 视觉↔数据交叉确认动作 | 常见成因 | 修复方向 |
|------|---------|------|---------------------|---------|---------|
| 空隙 / 缝隙 | 相邻面之间出现细长未填充条带 | 几何 | `query_feature_attributes` 数 `Shape_Area < 容差` 的细长图斑；或核对要素数是否偏多 | 容差过小/未对齐、未 Dissolve、源数据本身有缝 | 提高 XY 容差、对结果做 Dissolve、检查源数据拓扑 |
| 孔洞 | 面内部出现本不该有的空白洞 | 几何 | 数要素数是否异常偏多；查洞周边图斑面积 | 输入有孔、Union/Erase 误擦、多部件丢失 | 检查输入几何、修复几何(RepairGeometry)、复核 Erase 范围 |
| 碎屑 sliver | 大量极小、细长无意义碎片 | 几何 | `sql_where="Shape_Area < 1e-6"`（按单位调阈值）数占比 | 叠加/裁剪产生拓扑碎屑、容差不当 | Dissolve 合并、按面积阈值剔除、调容差 |
| 不连续 / 断裂 | 本应连续的带/面出现断口 | 几何 | 数要素数、查断口两侧要素 | 缓冲断裂、融合字段错误、源要素断开 | 复核 Buffer/Dissolve 参数、检查融合字段 |
| 错位 / 偏移 | 结果与参考层整体或局部错开 | 坐标系/几何 | `get_data_properties` 比对结果与参考层 `coordinate_system.name`/`wkid` 与 `extent` | CRS 不一致、缺投影定义、错误地理变换 | 统一坐标系、Define/Project、指定地理变换 |
| 覆盖缺失 / 缺角 | 结果未填满应覆盖范围、边缘缺块 | 几何/数据 | 比对结果 `extent` 与参考层 `extent`；数要素数 | 裁剪范围错、输入不全、选择集遗漏 | 复核裁剪/范围要素、检查输入完整性 |
| 超出参考边界 | 结果溢出研究区/裁剪范围之外 | 几何 | 比对 `extent` 是否超出参考 `extent` | 裁剪未生效、用错范围要素 | 确认裁剪要素正确并重跑 |
| 整体平移 / 形变 | 形状被拉伸/压扁，或整体平移 | 坐标系 | `get_data_properties` 比对 `coordinate_system`（投影/基准面）、`unit` | 投影错误、地理基准面变换缺失 | 用正确投影 Project、补地理变换 |
| 要素全空 / 全覆盖 | 图面空白，或整幅被单一面铺满 | 数据 | `get_data_properties` 看 `feature_count`；`query_feature_attributes` 看 `total` | 选择集为空、输入路径错、Buffer 距离过大 | 检查输入与选择条件、复核参数量级 |

## B. 各操作类型条目

### Clip 裁剪（`arcpy.analysis.Clip`）
- **必叠参考层**：裁剪要素（clip_features，红色空心轮廓）
- **正面信号**：结果完整填满裁剪范围、外边界与裁剪轮廓吻合、范围内无遗漏
- **负面信号**：
  - 结果未填满、缺角【几何/数据｜覆盖缺失】
  - 边界溢出裁剪轮廓【几何｜超出参考边界】
  - 边缘出现细碎条带【几何｜碎屑】
- **视觉↔数据交叉**：比对结果 `extent` ≈ 裁剪要素 `extent`（不应明显超出）；边缘碎屑→`sql_where="Shape_Area < 阈值"` 数占比

### Erase 擦除（`arcpy.analysis.Erase`）
- **必叠参考层**：擦除要素（erase_features，半透明填充以示被挖区域）
- **正面信号**：擦除要素覆盖处被正确镂空、保留区完整连续
- **负面信号**：
  - 应镂空处仍有面【几何｜覆盖缺失/误保留】
  - 保留区被多挖出孔洞【几何｜孔洞】
  - 边界处碎屑【几何｜碎屑】
- **视觉↔数据交叉**：擦除区抽样 `query_feature_attributes` 确认无落入擦除范围的要素；数要素数是否合理

### Intersect 相交（`arcpy.analysis.Intersect`）
- **必叠参考层**：两个输入层（不同色半透明）
- **正面信号**：结果仅出现在两输入**公共**区域、拼接无缝、属性含双方字段
- **负面信号**：
  - 结果超出公共区【几何｜超出参考边界】
  - 公共区有空洞/未生成【几何｜孔洞/覆盖缺失】
  - 大量碎屑【几何｜碎屑】
- **视觉↔数据交叉**：结果 `extent` 应落在两输入 `extent` 交集内；碎屑→面积阈值计数

### Union 联合（`arcpy.analysis.Union`）
- **必叠参考层**：两个输入层
- **正面信号**：覆盖两输入并集、分区拼接完整无缝、各分区属性可区分
- **负面信号**：
  - 并集范围有缺块【几何｜覆盖缺失】
  - 拼接缝隙/碎屑【几何｜空隙/碎屑】
  - FID 字段异常（-1 行过多可疑）【数据】
- **视觉↔数据交叉**：结果 `extent` ≈ 两输入并集；`sql_where="FID_xxx = -1"` 数占比是否异常

### Identity 标识（`arcpy.analysis.Identity`）
- **必叠参考层**：输入层 + 标识层
- **正面信号**：保留输入范围、叠加上标识层属性、范围不超出输入
- **负面信号**：范围超出输入【几何｜超出参考边界】、碎屑【几何｜碎屑】、标识属性缺失【数据】
- **视觉↔数据交叉**：结果 `extent` ≈ 输入 `extent`；抽样查标识字段非空

### Buffer 缓冲区（`arcpy.analysis.Buffer`）
- **必叠参考层**：源要素（point/line/polygon，醒目色）
- **正面信号**：缓冲带均匀环绕源要素、宽度一致、`dissolve` 时合并为连续面
- **负面信号**：
  - 宽度不均/异常膨胀【数据｜距离单位或量级错】
  - 缓冲带断裂【几何｜不连续】
  - 整幅铺满（距离过大）【数据｜全覆盖】
  - 未环绕源要素/偏移【坐标系｜错位】
- **视觉↔数据交叉**：`get_data_properties` 看结果 `extent` 较源扩张幅度是否≈缓冲距离；CRS `unit` 与距离单位是否匹配（米 vs 度）；要素数变化是否符合 `dissolve` 设置

### Dissolve 融合（`arcpy.analysis.Dissolve`）
- **必叠参考层**：融合前要素（细轮廓）或研究区范围
- **正面信号**：同类要素合并为连续成片大面、内部边界消失、要素数显著减少
- **负面信号**：
  - 相邻同类间残留细缝【几何｜空隙】
  - 残留碎屑【几何｜碎屑】
  - 该合并的未合并（融合字段错）【数据/几何】
- **视觉↔数据交叉**：`get_data_properties` 看 `feature_count` 应较融合前明显下降；缝隙/碎屑→`sql_where="Shape_Area < 阈值"` 计数

### Merge 合并（`arcpy.management.Merge`）
- **必叠参考层**：各输入层（不同色）
- **正面信号**：所有输入要素汇入同一层、范围为各输入并集、字段对齐
- **负面信号**：某输入整体缺失【数据｜覆盖缺失】、字段错位/空值激增【数据】、坐标系不一致致错位【坐标系｜错位】
- **视觉↔数据交叉**：结果 `feature_count` ≈ 各输入要素数之和；`extent` ≈ 各输入并集；CRS 一致性

### SpatialJoin 空间连接（`arcpy.analysis.SpatialJoin`）
- **必叠参考层**：目标要素 + 连接要素
- **正面信号**：目标要素几何不变、附加上连接层属性、`Join_Count` 合理
- **负面信号**：
  - 几何被改变/丢失【几何】
  - 连接属性大量空值【数据｜空值率高】
  - `Join_Count` 普遍为 0（匹配关系或容差错）【数据】
- **视觉↔数据交叉**：`query_feature_attributes` 看 `Join_Count=0` 占比、连接字段空值率；要素数应≈目标要素数

### 分类 / 评价制图（唯一值 unique_value / 分级 graduated / classed）
- **必叠参考层**：研究区范围（红色空心轮廓）
- **正面信号**：各类别连续成片、研究区内无未着色白斑、类别数与预期一致
- **负面信号**：
  - 研究区内有白斑/空洞【几何｜覆盖缺失/孔洞】
  - 异常孤立碎块【几何｜碎屑】
  - 某类别完全缺失或异常占满全图【数据】
- **视觉↔数据交叉**：`query_feature_attributes` 按分类字段统计各类别计数与空值率；白斑区核对 `feature_count`/`extent` 是否覆盖研究区

### 投影变换 Project（`arcpy.management.Project` / `DefineProjection`）
- **必叠参考层**：一个已知正确 CRS 的参考层（同区域）
- **正面信号**：结果与参考层空间叠合、位置/形状一致、`extent` 落在合理地理范围
- **负面信号**：
  - 与参考层整体错位/平移【坐标系｜错位】
  - 形状拉伸/压扁【坐标系｜整体形变】
  - `extent` 数值异常（如投影坐标却是经纬度量级）【坐标系/数据】
- **视觉↔数据交叉**：`get_data_properties` 比对结果与参考层 `coordinate_system.name`/`wkid`/`unit` 是否一致、`extent` 量级是否匹配（度 ≈ ±180/±90 vs 投影米级大数）

## C. 兜底（未列出的工具）

直接用 **A. 通用症状库**：先确认输出已生成（`list_gdb_contents`），再按合同 `expected_result` /
`validation_criteria` 列预期视觉特征作正面信号，逐条排查通用症状作负面信号，命中即按主表交叉确认与溯源。
