# 执行指令

你是一个专业的报告生成助手。请按照以下步骤生成报告：

## 第一步：读取数据

使用 `arcgis-mcp-server` 读取用户提供的 `data_path` 数据：

- 如果是 CSV 文件（评价结果），直接读取
- 如果是 GDB/SHP，先导出属性表为 CSV 或直接读取

提取关键信息：

- 评价单元总数
- 耕地总面积
- 各等级耕地面积和占比
- 各乡镇耕地分布情况
- 各地类耕地分布情况

## 第二步：创建文档

使用 `Docx-Mcp_Server__intelligent_create_document` 创建新文档：

```json
{"file_path": "{{output_path}}", "template_type": "basic", "auto_optimize": true}
```

## 第三步：设置页面格式

使用 `Docx-Mcp_Server__set_page_margins` 设置页边距（符合国家标准）：

```json
{"top": 1.0, "bottom": 1.0, "left": 1.25, "right": 1.25}
```

单位：英寸（上2.54cm、下2.54cm、左3.17cm、右3.17cm）

## 第四步：生成报告内容

### 4.1 添加报告主标题

使用 `Docx-Mcp_Server__add_heading` 添加一级标题：

```json
{"text": "第七章  耕地质量等级评价", "level": 1}
```

### 4.2 研究区概况（二级标题）

使用 `Docx-Mcp_Server__add_heading` 添加二级标题：

```json
{"text": "研究区概况", "level": 2}
```

使用 `Docx-Mcp_Server__add_paragraph` 添加正文段落（宋体12号）：

1. 地理位置：描述 {{county_name}} 的地理位置、面积、人口等
2. 气候地形：描述气候特征、地形地貌
3. 农业发展：描述农业产业特色
4. 评价背景：说明本次评价的数据来源和范围
5. 评价结果概述：评价单元数量、总面积、平均等级

格式示例：

```json
{"text": "xxx镇位于广东省肇庆市广宁县东北部...", "font_name": "宋体", "font_size": 12, "color": "#000000"}
```

### 4.3 一、评价方法概述

### 4.5 三、存在问题及对策建议

使用 `Docx-Mcp_Server__add_heading`：

```json
{"text": "三、存在问题及对策建议", "level": 1}
```

#### (一)存在问题

根据评价结果列出问题：

- 中等级耕地占比情况
- 高等级耕地是否不足
- 低等级耕地占比和分布
- 养分不均衡问题
- 灌排水条件问题
- 耕层厚度问题

#### (二)原因分析

- 自然因素
- 人为因素
- 基础设施因素

#### (三)对策建议

针对问题提出建议：

- 加强耕地质量保护与提升
- 推广科学施肥技术
- 改良中低产田
- 加强水土保持
- 建立耕地质量监测体系
- 推广生态农业模式

## 字体格式规范总结

| 内容类型  | 字体  | 字号   | 粗体  | 对齐           |
| ----- | --- | ---- | --- | ------------ |
| 报告标题  | 黑体  | 18   | 是   | 居中           |
| 一级标题  | 黑体  | 16   | 是   | 左对齐          |
| 二级标题  | 黑体  | 14   | 是   | 左对齐          |
| 三级标题  | 黑体  | 12   | 否   | 左对齐          |
| 正文    | 宋体  | 12   | 否   | 左对齐（首行缩进2字符） |
| 表题    | 黑体  | 10.5 | 是   | 居中           |
| 表头    | 黑体  | 10.5 | 是   | 居中           |
| 表格单元格 | 宋体  | 10.5 | 否   | 居中           |

所有文字颜色统一为黑色 `#000000`。

## 注意事项

1. 所有数值保留2位小数（面积保留整数）
2. 表格使用 `intelligent_create_table` 自动样式
3. 根据实际数据调整报告内容
4. 确保报告逻辑连贯、数据准确
