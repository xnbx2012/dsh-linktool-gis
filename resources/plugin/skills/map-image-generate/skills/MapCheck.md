# 图件质量检查规范

## 1. 目标

本文件用于指导地图生成后的图件质量检查。地图图件生成后，应调用 MiniMax MCP 的图像理解工具对输出图片进行检查，确保地图满足正式制图交付要求。

```text
mcp__MiniMax__understand_image

参数：
- image_source：输出 PNG 的绝对路径                                                      
- prompt：审图提示词（见第 4 节）
```

图件质量检查的核心目标是：

1. 检查制图要素是否齐全。
2. 检查图面布局是否合理。
3. 检查地图主体是否居中且未被裁切。
4. 检查图例、比例尺、指北针是否遮挡主图。
5. 检查标注是否清晰、正确、不过密。
6. 检查配色是否符合地图主题和字段语义。
7. 判断是否需要重新制图。

---

## 2. 检查时机

图件质量检查应在地图 PNG 生成后执行。

推荐流程：

```text
调用 create_map 生成 PNG
  ↓
确认 PNG 输出路径
  ↓
调用 mcp__MiniMax__understand_image 检查图件
  ↓
记录检查结果
  ↓
判断是否需要重新制图
  ↓
如需重制，调整 JSON 配置后再次生成
```

注意：如果当前 Skill 的 allowed-tools 仅允许 `color-style-mcp`，则 VLM 检查应由调用本 Skill 的上游 Agent 在地图生成后执行。

---

## 3. 检查内容

### 3.1 制图要素完整性

检查地图是否包含正式图件应有的基本要素：

- 地图标题；
- 主地图框；
- 图例；
- 比例尺；
- 指北针；
- 必要标注；
- 数据来源或说明，如任务要求；
- 坐标系说明，如任务要求；
- 制图时间或成果说明，如任务要求。

正式图件原则上不应缺少：

```text
标题
图例
比例尺
指北针
```

除非用户明确要求生成简图。

---

### 3.2 布局合理性

检查地图布局是否合理：

- 地图主体是否居中；
- 图面是否整体平衡；
- 是否存在大量空白；
- 主地图是否过小；
- 主地图是否过大导致裁切；
- 标题是否居中；
- 图例位置是否合理；
- 比例尺位置是否合理；
- 指北针位置是否合理；
- 图例、比例尺、指北针是否遮挡主图；
- 页面边距是否适中。

常见问题：

```text
地图主体偏左或偏右
地图主体过小
图例压住主图层
比例尺遮挡关键区域
指北针位置突兀
页面留白过多
地图边缘被裁切
```

---

### 3.3 配色合理性

检查配色是否符合地图主题和字段语义：

- 分级变量是否使用渐变色带；
- 分类变量是否使用定性色板；
- 有序等级变量是否体现顺序关系；
- 高值和低值颜色方向是否正确；
- 风险类高值是否突出；
- 水系是否使用蓝色系；
- 植被、生态、耕地质量是否使用绿色系或合理生态色带；
- 土地利用分类颜色是否符合常识；
- 背景图层是否与主图层冲突；
- 图例颜色是否与地图颜色一致。

常见问题：

```text
风险高值使用绿色导致误导
水域使用红色导致语义错误
分类图使用连续渐变色
分级图使用随机颜色
图例颜色与地图不一致
主图层和背景颜色对比不足
```

---

### 3.4 标注质量

检查标注是否清晰、合理：

- 必要标注是否出现；
- 标注字段是否正确；
- 标注文字是否清晰可读；
- 标注字号是否合适；
- 标注颜色是否与背景有足够对比；
- 是否有白色描边或 halo；
- 标注是否过密；
- 标注是否重叠；
- 标注是否被裁切；
- 标注是否遮挡重要图形。

常见问题：

```text
标注重叠严重
标注字号过小
标注颜色与背景接近
标注被地图边缘裁切
要素太多导致满图文字
标注字段不是用户要求字段
```

---

### 3.5 图例质量

检查图例是否可读、准确：

- 图例是否存在；
- 图例标题是否清晰；
- 图例项是否完整；
- 图例颜色是否与地图一致；
- 分类顺序是否合理；
- 连续变量是否从低到高排列；
- 风险等级是否从低风险到高风险排列；
- 图例文字是否可读；
- 图例是否过大；
- 图例是否遮挡主图。

---

### 3.6 整体可读性和美观性

检查图件整体是否适合交付：

- 地图主题是否一眼可识别；
- 主图层是否突出；
- 辅助图层是否弱化；
- 图面是否清爽；
- 文字是否清晰；
- 符号是否协调；
- 色彩是否过饱和或过暗；
- 是否适合报告、汇报或成果交付。

---

## 4. VLM 审图提示词

调用 VLM MCP 工具时，可使用如下提示词：

```text
请作为 GIS 地图制图质检专家，检查这张地图是否满足正式地图制图要求。

请重点检查：
1. 制图要素是否完整：标题、图例、比例尺、指北针、必要标注是否齐全。
2. 布局是否合理：地图主体是否居中，图例、比例尺、指北针是否遮挡主图，是否存在过多空白或裁切。
3. 配色是否合理：是否符合地图主题，分级变量是否使用渐变色带，分类变量颜色是否容易区分，图例颜色是否与地图一致。
4. 标注是否清晰：是否出现必要标注，是否有重叠、过密、裁切或字号过小问题。
5. 整体可读性和美观性：是否适合正式报告或成果交付。

请输出：
- 总体评价：合格 / 需要修改 / 不合格
- 主要问题列表
- 修改建议
- 是否建议重新制图
```

## 6. 评分建议

可按 100 分制进行图件质量评分：

| 检查项 | 分值 |
|---|---:|
| 制图要素完整性 | 20 |
| 布局合理性 | 20 |
| 符号与配色 | 20 |
| 标注质量 | 15 |
| 图例与说明 | 10 |
| 数据表达准确性 | 10 |
| 整体美观 | 5 |

评分解释：

```text
90-100：优秀，可直接交付
80-89：合格，可交付
70-79：建议修改
70 以下：不合格，必须重制
```

---

## 7. 重新制图规则

如果出现以下问题，应调整参数并重新制图：

1. 缺少标题、图例、比例尺、指北针等关键制图要素。
2. 地图主体明显不居中。
3. 图例、比例尺、指北针或标注遮挡主图关键区域。
4. 标注严重重叠或不可读。
5. 配色与地图主题明显不符。
6. 分级变量颜色方向错误。
7. 分类变量颜色过于接近，无法区分。
8. 图件被裁切。
9. 地图主体过小或留白过多。
10. VLM 明确建议重新制图。

默认最多重制：

```text
2 次
```

如果多次重制后仍存在轻微问题，应在最终说明中明确指出。

## 9. 注意事项

1. 图件检查必须基于实际生成的图片，不得凭想象判断。
2. 如果 VLM 工具不可用，应在最终回复中说明未进行视觉检查。
3. VLM 检查结果应作为重制依据，但也要结合 GIS 制图常识判断。
4. 对于正式成果图，缺少标题、图例、比例尺、指北针通常应视为严重问题。
5. 若用户明确要求简图，可适当降低制图要素要求，但仍需说明。
6. 图件检查结果应反馈到符号系统、配色方案和布局设计中。
