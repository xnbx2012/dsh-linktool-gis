# 配色方案设计规范

## 1. 目标

本文件用于指导地图制图中的配色方案设计。配色方案应根据地图主题、字段语义、字段类型、属性值特征和用户提供的色带参考进行选择。

配色方案设计的核心目标是：

1. 确保地图主题表达准确。
2. 确保颜色符合地理语义和用户习惯。
3. 确保连续变量和分级变量使用合理渐变色带。
4. 确保离散类别变量使用易区分的定性色板。
5. 确保图例颜色与地图符号一致。
6. 避免颜色误导、过饱和、对比不足或高低值方向反转。

---

## 2. 配色决策优先级

配色选择应遵循以下优先级：

```text
用户明确指定配色
  ↓
用户提供的色带参考
  ↓
地图主题
  ↓
字段名语义
  ↓
字段数据类型和取值特征
  ↓
默认制图配色规范
```

说明：

1. 用户明确指定颜色时，优先使用用户要求。
2. 用户提供色带参考时，应优先从参考色带中选择。
3. 如果用户未指定，则根据主题和字段语义选择。
4. 如果主题不明确，则根据字段类型选择默认配色。

---

## 3. 连续变量配色

连续变量和分级变量应优先使用渐变色带。

### 3.1 适用字段

```text
人口密度
GDP
高程
坡度
NDVI
风险指数
适宜性分值
耕地质量分
污染浓度
生态敏感性指数
面积
比例
得分
```

### 3.2 设计原则

1. 使用从浅到深的渐变色带。
2. 低值和高值颜色方向必须符合字段语义。
3. 避免使用无序随机颜色。
4. 默认 5 级色带。
5. 图例应从低值到高值排列。
6. 高值是否使用深色、红色或绿色，取决于主题语义。

---

## 4. 离散类别配色

离散类别变量应使用定性色板。

### 4.1 适用字段

```text
土地利用类型
地类名称
行政区名称
生态系统类型
设施类型
保护区类型
道路类型
用地性质
```

### 4.2 设计原则

1. 类别之间颜色差异明显。
2. 不使用连续渐变色带。
3. 颜色不应暗示不存在的大小顺序。
4. 类别过多时，应考虑合并小类或使用“其他”。
5. 图例标签应清晰、简洁、尽量中文化。

---

## 5. 有序等级配色

有序等级变量虽然通常是离散值，但必须体现顺序关系。

### 5.1 适用字段

```text
风险等级
质量等级
适宜性等级
敏感性等级
污染等级
灾害等级
优良中差
高中低
一级二级三级
```

### 5.2 设计原则

1. 使用顺序色带。
2. 等级顺序必须清晰。
3. 图例顺序应与等级顺序一致。
4. 风险类通常低值浅色、高值红色或深色。
5. 质量类和适宜性类需要根据“高值好”或“高值差”确定颜色方向。

## 6. 常用主题色带

### 6.1 水文 / 降水 / 水资源

适用主题：

```text

湖泊
水资源
降水
湿度
流域
水系密度
```

推荐色带：

```text
浅蓝 → 中蓝 → 深蓝
```

```text
#EFF3FF
#BDD7E7
#6BAED6
#3182BD
#08519C
```

[189, 215, 231, 90]

### 6.4 适宜性评价

适用主题：

```text
建设适宜性
生态适宜性
农业适宜性
开发适宜性
选址适宜性
```

如果字段语义是“越高越好”：

```text
低值：浅黄或橙色
高值：深绿
```

推荐色带：

```text
#FEE08B
#D9EF8B
#A6D96A
#66BD63
#1A9850
```

如果字段语义是“越高越不适宜”：

```text

```

推荐色带：

```text
#1A9850
#A6D96A
#FFFFBF
#FDAE61
#D73027
```

注意：适宜性类地图必须判断颜色方向，不能机械套用。

## 7. 土地利用分类配色

土地利用分类应使用定性色板。

推荐：

| 类别 | 推荐颜色 | HEX | RGB-A |
|---|---|---|---|
| 耕地 | 黄色或浅黄 | `#F4E04D` | `[244, 224, 77, 90]` |
| 林地 | 绿色 | `#3A923A` | `[58, 146, 58, 90]` |
| 草地 | 黄绿色 | `#9ACD32` | `[154, 205, 50, 90]` |
| 水域 | 蓝色 | `#4A90E2` | `[74, 144, 226, 90]` |
| 建设用地 | 红色、粉红或灰红 | `#D9534F` | `[217, 83, 79, 90]` |
| 未利用地 | 灰色 | `#BDBDBD` | `[189, 189, 189, 90]` |
| 裸地 | 棕色或浅棕 | `#C2A679` | `[194, 166, 121, 90]` |
| 湿地 | 青绿色 | `#66C2A5` | `[102, 194, 165, 90]` |

## 8. 点、线、面配色规则

### 8.1 点图层

| 点类型 | 推荐颜色 |
|---|---|
| 普通点 | 蓝色，白色描边 |
| 重点点 | 红色或橙色，白色描边 |
| 监测点 | 蓝色或紫色 |
| 设施点 | 按设施类型使用定性色 |
| 风险点 | 黄橙红 |

### 8.2 线图层

| 线类型 | 推荐颜色 |
|---|---|
| 河流 / 水系 | 蓝色 |
| 道路 | 灰色、橙色或红色 |
| 行政边界 | 深灰色 |
| 路径 / 规划线 | 高亮红色、蓝色或紫色 |
| 管线 | 按类型使用定性色 |

### 8.3 面图层

| 面类型 | 推荐颜色 |
|---|---|
| 研究区范围 | 半透明浅色填充 + 高亮边界 |
| 背景面 | 低饱和度浅灰或浅色 |
| 专题面 | 根据字段类型和主题选择 |
| 行政区面 | 浅色分类或灰色边界 |

## 9. 禁止和警告规则

### 9.1 禁止错误配色

```text
水域不要默认使用红色。
植被不要默认使用紫色或红色。
风险高值不要使用浅绿色。
分类变量不要使用连续渐变色。
连续变量不要使用大量随机离散颜色。
高低值颜色方向不能反转。
```

### 9.2 警告情况

以下情况应提醒用户或在制图说明中说明：

1. 用户指定配色与主题常识冲突。
2. 字段语义不明确，颜色方向无法判断。
3. 类别数量过多，颜色区分困难。
4. 色带级数过多，图例难以阅读。
5. 背景图层颜色与主图层冲突。

## 11. 注意事项

1. 配色必须服从主题和字段语义。
2. 用户明确指定配色时优先使用用户要求，但如明显不合理应提醒。
3. 连续变量和分级变量优先使用渐变色带。
4. 离散类别变量使用定性色板。
5. 有序等级变量使用顺序色带。
6. 风险、污染、灾害类地图通常使用黄橙红。
7. 生态、植被、耕地质量类地图通常使用绿色系。
8. 水文和水资源类地图通常使用蓝色系。
9. 图例颜色必须与地图符号一致。
10. 配色方案应接受 VLM 图件检查反馈，并根据反馈调整。
