# 字段类型判断规范

## 1. 目标

本文件用于指导地图制图中的字段类型判断。字段类型判断是地图制图的关键步骤，直接决定符号系统、分类方法、配色方案和图例表达方式。

字段类型判断的核心目标是：

1. 判断字段是否适合作为主制图字段。
2. 判断字段是连续变量、离散类别、有序等级还是二元变量。
3. 判断字段是否适合作为标注字段。
4. 为符号系统设计和配色方案设计提供依据。

---

## 2. 判断依据

字段类型判断应综合以下信息：

1. 用户需求中的制图主题。
2. 字段名称和字段别名。
3. 字段数据类型。
4. 属性表样本值。
5. 唯一值数量。
6. 字段值是否存在自然顺序。
7. 字段值是否为空或异常。
8. 字段是否为系统字段。

不得仅凭字段名武断判断，应尽量结合属性表样本和工具返回结果。

---

## 3. 连续数值型字段

### 3.1 特征

连续数值型字段通常具有以下特征：

- 字段类型为 Integer、Double、Float、Single、SmallInteger 等数值类型；
- 唯一值数量较多；
- 存在最大值和最小值；
- 数值之间有大小关系；
- 适合进行分级；
- 适合表达强度、指数、分值、密度、浓度、比例等。

### 3.2 典型字段

```text
GDP
人口密度
高程
坡度
NDVI
污染浓度
耕地质量分
生态敏感性指数
适宜性指数
风险指数
面积
长度
数量
比例
得分
产量
强度
密度
```

### 3.3 推荐制图方式

```text
符号系统：graduated_colors
分类方法：natural_breaks / equal_interval / quantile / standard_deviation
配色方案：渐变色带
默认等级数：5
```

### 3.4 判断示例

```text
字段名：risk_score
字段类型：Double
样本值：12.5, 36.8, 55.2, 80.1
判断：连续数值型字段
推荐：分级设色，黄橙红渐变
```

---

## 4. 离散类别字段

### 4.1 特征

离散类别字段通常具有以下特征：

- 字段类型多为 String，也可能是少量编码值；
- 唯一值数量相对有限；
- 字段值表达类别或类型；
- 类别之间没有明确大小顺序；
- 不适合使用渐变色带。

### 4.2 典型字段

```text
土地利用类型
地类名称
行政区名称
生态系统类型
保护区类型
道路类型
设施类型
用地性质
类别
类型
名称
```

### 4.3 推荐制图方式

```text
符号系统：unique_value
配色方案：定性色板
图例排序：按业务习惯或用户指定顺序
```

### 4.4 判断示例

```text
字段名：landuse_type
字段类型：String
样本值：耕地、林地、水域、建设用地
判断：离散类别字段
推荐：唯一值分类，使用土地利用定性色板
```

---

## 5. 有序等级字段

### 5.1 特征

有序等级字段通常具有以下特征：

- 唯一值数量较少；
- 字段值之间存在明确顺序；
- 字段表达等级、质量、风险、适宜性、敏感性等；
- 字段可以是文本，也可以是编码值；
- 虽然离散，但配色应体现顺序关系。

### 5.2 典型字段

```text
耕地质量等级
生态风险等级
适宜性等级
敏感性等级
灾害风险等级
污染等级
优良中差
高中低
一级二级三级
I II III IV V
A B C D
```

### 5.3 推荐制图方式

```text
符号系统：unique_value 或 classed
配色方案：顺序色带
图例排序：按等级从低到高或从高到低，需符合主题语义
```

### 5.4 判断示例

```text
字段名：risk_level
字段类型：String
样本值：低风险、中风险、高风险
判断：有序等级字段
推荐：顺序色带，低风险浅黄，高风险红色
```

```text
字段名：quality_level
字段类型：String
样本值：一等、二等、三等、四等
判断：有序等级字段
推荐：顺序色带，高质量深绿，低质量橙色或浅黄
```

---

## 6. 二元字段

### 6.1 特征

二元字段通常只有两个主要取值，用于表达是否、有无、通过与否等。

常见取值：

```text
是 / 否
有 / 无
通过 / 未通过
达标 / 不达标
适宜 / 不适宜
1 / 0
True / False
```

### 6.2 推荐制图方式

```text
符号系统：unique_value
配色方案：强对比色
```

推荐配色：

```text
是 / 适宜 / 达标 / 通过：绿色或蓝色
否 / 不适宜 / 不达标 / 未通过：红色、橙色或灰色
```

### 6.3 判断示例

```text
字段名：is_suitable
字段类型：String
样本值：适宜、不适宜
判断：二元字段
推荐：适宜用绿色，不适宜用红色或橙色
```

---

## 7. 标识字段和系统字段

### 7.1 特征

标识字段和系统字段通常用于数据管理，不适合作为主制图字段。

典型字段：

```text
OBJECTID
FID
OID
Shape
Shape_Length
Shape_Area
GlobalID
GUID
ID
编号
系统编号
内部编码
```

### 7.2 处理原则

除非用户明确要求，否则不要使用这些字段作为主制图字段。

这些字段可用于：

- 数据识别；
- 调试；
- 查询；
- 个别情况下作为标注编号。

但通常不适合：

- 作为专题图分类字段；
- 作为分级设色字段；
- 作为图例字段。

---

## 8. 标注字段判断

### 8.1 适合作为标注字段

适合标注的字段通常具有：

- 字段值简短；
- 含义明确；
- 用户容易理解；
- 与地图主题相关；
- 不会造成过度拥挤。

典型字段：

```text
名称
地名
行政区名称
村名
监测点名称
站点编号
设施名称
道路名称
河流名称
```

### 8.2 不适合作为标注字段

不适合标注的字段：

```text
长文本说明
系统编码
GlobalID
Shape_Length
Shape_Area
高精度小数值
大量唯一编号
```

### 8.3 标注密度判断

如果要素数量很多，应谨慎开启标注。

建议：

- 点要素较多时，只标注重点点；
- 面要素过密时，只标注主要区域；
- 线要素过密时，避免全部道路或河流标注；
- 如果用户未明确要求，可默认关闭高密度图层标注。

## 10. 注意事项

1. 字段类型判断必须基于字段结构和属性样本，不得编造字段含义。
2. 文本字段不一定都是分类字段，也可能是有序等级字段。
3. 数值字段不一定都适合分级，如果只是编号或代码，应避免作为连续变量处理。
4. 分类字段类别过多时，不宜直接做唯一值图，应考虑聚合或选择重点类别。
5. 等级字段必须注意颜色方向，避免高低含义反转。
6. 标注字段应考虑图面拥挤程度，不应默认全部标注。
