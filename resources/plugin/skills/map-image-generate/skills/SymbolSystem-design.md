# 符号系统设计规范

## 1. 目标

本文件用于指导地图制图中的符号系统设计。符号系统应根据数据几何类型、字段类型、地图主题和图层主次关系进行选择，确保地图表达准确、清晰、美观。

符号系统设计的核心目标是：

1. 让地图主题表达清晰。
2. 让主图层和辅助图层层次分明。
3. 让字段类型与 renderer 类型匹配。
4. 避免错误使用符号系统导致误读。
5. 为 `color-style-mcp` 的 `create_map` 构建合理 JSON 配置。

---

## 2. 支持的主要 renderer 类型

当前地图制图 Skill 中主要使用以下 renderer 类型：

```text
simple
unique_value
graduated_colors
classed
```

| Renderer | 适用场景 |
|---|---|
| `simple` | 无专题字段、研究区范围、边界、背景图层 |
| `unique_value` | 离散类别字段、二元字段、部分等级字段 |
| `graduated_colors` | 连续数值字段、指数、分值、密度、浓度 |
| `classed` | 已有等级字段、手动分类结果、有序等级变量 |

---

## 3. 简单符号 `simple`

### 3.1 适用场景

`simple` 适合不需要根据字段变化设置符号的图层。

常见用途：

- 研究区范围；
- 行政边界；
- 背景面；
- 缓冲区范围；
- 裁剪范围；
- 无专题字段的辅助图层。

### 3.2 面符号示例

```json
"renderer": {
  "type": "simple",
  "symbol": {
    "type": "polygon",
    "fill_color": [255, 255, 200, 40],
    "outline_color": [200, 0, 0, 100],
    "outline_width": 2
  }
}
```

### 3.3 点符号示例

```json
"renderer": {
  "type": "simple",
  "symbol": {
    "type": "point",
    "color": [30, 120, 220, 100],
    "size": 6,
    "outline_color": [255, 255, 255, 100],
    "outline_width": 1
  }
}
```

### 3.4 线符号示例

```json
"renderer": {
  "type": "simple",
  "symbol": {
    "type": "line",
    "color": [50, 120, 220, 100],
    "width": 1.5
  }
}
```

## 4. 唯一值符号 `unique_value`

### 4.1 适用场景

`unique_value` 适合离散分类字段。

典型场景：

- 土地利用类型；
- 地类名称；
- 行政区名称；
- 设施类型；
- 道路类型；
- 保护区类型；
- 二元字段；
- 部分有序等级字段。

### 4.2 设计原则

1. 每个类别对应一种颜色或符号。
2. 类别之间颜色应易于区分。
3. 离散类别不应使用连续渐变色。
4. 图例标签应尽量使用中文名称或字段别名。
5. 类别过多时应谨慎使用，可聚合为“其他”。

### 4.3 JSON 示例

```json
"renderer": {
  "type": "unique_value",
  "field": "landuse_type",
  "classes": [
    {
      "value": "耕地",
      "label": "耕地",
      "symbol": {
        "fill_color": [244, 224, 77, 90],
        "outline_color": [120, 120, 120, 100],
        "outline_width": 0.5
      }
    },
    {
      "value": "林地",
      "label": "林地",
      "symbol": {
        "fill_color": [58, 146, 58, 90],
        "outline_color": [120, 120, 120, 100],
        "outline_width": 0.5
      }
    }
  ]
}
```

## 5. 分级设色 `graduated_colors`

### 5.1 适用场景

`graduated_colors` 适合连续数值型字段。

典型场景：

- 人口密度；
- GDP；
- 风险指数；
- 适宜性分值；
- 耕地质量分；
- 生态敏感性指数；
- 污染浓度；
- 高程；
- 坡度；
- NDVI。

### 5.2 设计原则

1. 使用渐变色带。
2. 数值从低到高的颜色变化应符合主题语义。
3. 默认使用 5 级。
4. 默认分类方法为 `natural_breaks`。
5. 如果用户提供阈值，应优先使用用户阈值。

### 5.3 JSON 示例

```json
"renderer": {
  "type": "graduated_colors",
  "field": "risk_score",
  "classification_method": "natural_breaks",
  "class_count": 5,
  "color_scheme": {
    "colors": [
      [255, 255, 178, 90],
      [254, 204, 92, 90],
      [253, 141, 60, 90],
      [240, 59, 32, 90],
      [189, 0, 38, 90]
    ]
  },
  "outline_color": [100, 100, 100, 100],
  "outline_width": 0.5
}
```

分级设色应优先把配色方案写入 `color_scheme.colors`。当只确定起止色时，可使用 `color_scheme.start_color` 和 `color_scheme.end_color` 由 MCP 自动插值。

### 5.4 分类方法选择

| 分类方法 | 适用场景 |
|---|---|
| `natural_breaks` | 默认推荐，适合多数自然分布数据 |
| `equal_interval` | 适合固定范围或均匀分布数据，如 0-100 分 |
| `quantile` | 适合希望每级要素数量接近 |
| `standard_deviation` | 适合表达偏离平均值程度 |

## 6. 分类符号 `classed`

### 6.1 适用场景

`classed` 适合已经存在分类或等级结果的字段。

典型场景：

- 风险等级；
- 质量等级；
- 适宜性等级；
- 污染等级；
- 人为分级结果；
- 政策标准分类；
- 用户指定分类。

### 6.2 设计原则

1. 分类顺序必须明确。
2. 有序等级应使用顺序色带。
3. 图例顺序应与等级顺序一致。
4. 风险类通常从低风险到高风险排列。
5. 质量类应根据语义决定高值颜色方向。

### 6.3 JSON 示例

```json
"renderer": {
  "type": "classed",
  "field": "risk_level",
  "classes": [
    {
      "label": "低",
      "symbol": {
        "fill_color": [255, 255, 178, 90],
        "outline_color": [100, 100, 100, 100],
        "outline_width": 0.5
      }
    },
    {
      "label": "中",
      "symbol": {
        "fill_color": [253, 141, 60, 90],
        "outline_color": [100, 100, 100, 100],
        "outline_width": 0.5
      }
    },
    {
      "label": "高",
      "symbol": {
        "fill_color": [189, 0, 38, 90],
        "outline_color": [100, 100, 100, 100],
        "outline_width": 0.5
      }
    }
  ]
}
```

## 7. 按几何类型选择符号

### 7.1 面图层

面图层常用于表达区域、范围、分类、分级结果。

推荐：

| 字段类型 | 推荐 renderer |
|---|---|
| 无专题字段 | `simple` |
| 离散类别字段 | `unique_value` |
| 连续数值字段 | `graduated_colors` |
| 有序等级字段 | `unique_value` 或 `classed` |

面图层符号建议：

- 填充色可设置透明度；
- 边界线不宜过粗；
- 主图层颜色应突出；
- 背景面应弱化；
- 分级面图使用渐变色带。

### 7.2 线图层

线图层常用于表达道路、水系、边界、管线等。

推荐：

| 线类型 | 推荐样式 |
|---|---|
| 河流 / 水系 | 蓝色，较细或按等级加粗 |
| 道路 | 灰色、橙色或红色，按道路等级设置线宽 |
| 行政边界 | 深灰色细线，可使用虚线 |
| 路径 / 规划线 | 高亮红色、蓝色或紫色，线宽较粗 |
| 管线 | 按类型使用定性色 |

### 7.3 点图层

点图层常用于表达监测点、设施点、采样点等。

推荐：

| 点类型 | 推荐样式 |
|---|---|
| 普通点 | 蓝色圆点，白色描边 |
| 重点点 | 红色或橙色圆点，白色描边 |
| 分类点 | 定性色板 |
| 等级点 | 颜色或大小表达等级 |
| 监测点 | 蓝色或紫色，适当描边 |

点图层数量较多时，避免全部标注。

## 8. 图层组织规则

多图层地图必须明确主次关系。

推荐图层顺序：

```text
底图或背景面
  ↓
辅助面图层
  ↓
主专题面图层
  ↓
线状图层
  ↓
点状图层
  ↓
边界线
  ↓
标注
```

表达原则：

1. 主图层使用醒目符号。
2. 辅助图层使用弱化符号。
3. 背景图层低饱和、低透明。
4. 边界线清晰但不抢主题。
5. 点图层应位于面图层上方。
6. 线图层应位于面图层上方。
7. 标注位于最上层。
8. 图例、比例尺、指北针不能遮挡主图层关键区域。

## 10. 注意事项

1. 连续变量不要使用大量随机离散颜色。
2. 离散类别变量不要使用连续渐变色带。
3. 等级字段必须体现顺序关系。
4. 主图层和辅助图层不能同等突出。
5. 边界线不宜过粗，避免遮挡面状专题表达。
6. 点图层要考虑点位密度和遮挡问题。
7. 标注必须谨慎使用，避免图面拥挤。
8. 符号系统必须与图例保持一致。
